# 1

- [There have been names that I have loved to hear,]{lang="en"}\
  [曾聽地上許多美好的名，]{lang="zh"}
- [But never has there been a name so dear]{lang="en"}\
  [但從沒有一名如此好聽，]{lang="zh"}
- [To this heart of mine, as the name divine,]{lang="en"}\
  [我心真愛戴這神聖的名，]{lang="zh"}
- [The precious name of Jesus.]{lang="en"}\
  [耶穌這寶貴、寶貴的名。]{lang="zh"}

- [Jesus is the sweetest name I know,]{lang="en"}\
  [耶穌是最甜美的聖名，]{lang="zh"}

  [祂一生所是，正合祂聖名，]{lang="zh"}

  [故我願愛主、奉獻我生命，]{lang="zh"}

  [哦，耶穌，耶穌，最甜美的名。]{lang="zh"}
